# Delta Force 0 — Web/PWA

Version web installable du jeu.

- `index.html` : jeu
- `assets/video/` : cinématiques MP4 séparées
- `assets/media/` : images et musiques séparées
- `manifest.webmanifest` + `sw.js` : installation PWA

Déployer sur HTTPS (Vercel recommandé). Sur Android/Chrome, ouvrir le site puis utiliser **Installer le jeu** ou **Ajouter à l’écran d’accueil**.
